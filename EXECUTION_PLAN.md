# 🚀 План доработок и исправлений (Контекст для Codex)

## 📊 Статус реализации (29.10.2026)

### Шаг 5а. Устранение критических ошибок ✅ (PR #85)
*   **Задача (5): Исправление ложного срабатывания напоминаний служения в среду.**
    *   **Результат:** ✅ Напоминание служения теперь корректно отсчитывается от воскресенья,
        напоминание задачи — от её фактического дня выполнения (например, «спевка −1» от среды).
    *   **Интерфейс:** В карточке напоминания указывается: «📅 Срок: за N дн. до воскресенья»
        или «… до дня задачи — ср (вс -4)». Период «с — по» учитывает воскресенье недели.

### Шаг 5б. Публикация графика в чат ✅ (PR #86)
*   **Задачи (1, 3): Оптимизация вывода и логика обновлений.**
    *   **Логика вывода:** ✅ График выводится по одному участнику в строке, имена без склонения.
    *   **Логика обновлений:** ✅ Первая публикация закрепляется. Правка редактирует то же сообщение
        (если оно доступно младше 48 часов и не удалено). Если нет — новая публикация.
    *   **Diff-блок:** ✅ Под графиком — все изменения месяца с первой публикации
        (формат: «08.11 Денис → Филипп»).
    *   **Уведомление:** ✅ Ответом на закреплённое сообщение идёт краткое уведомление
        с новыми изменениями и упоминаниями (@username).

### Шаг 5в. Модуль замен в «📅 График» ✅ (PR #90)
*   **Задачи (9, 16, 20): Рефакторинг экрана замен.**
    *   **Логика интерфейса:** ✅ Кнопка «🔁 Замены» перенесена в раздел «📅 График».
    *   **Группировка по неделям:** ✅ Выбор по неделям (ISO номер: «44 нед. 26.10–01.11»),
        не по отдельным датам задач.
    *   **Экран недели:** ✅ Открывает список всех задач недели с датами и людьми.
        Далее выбор конкретной задачи для замены.
    *   **Контекст экрана:** ✅ На экранах замены сверху — текущий график месяца
        (утверждённый или черновик) с выделением текущей недели (▶️).
    *   **Навигация:** ✅ Кнопка «Далее ➡️» над остальными. Нижний ряд: «⬅️ К неделе» и «📅 К графику».

### Шаг 5г. Реструктуризация напоминаний служения ⬜
*   **Задача (7): Перенос раздела напоминаний в Задачи.**
    *   Раздел «Напоминания и шаблоны» → внутри раздела «Задачи»;
        напоминание без задачи — пунктом «Всё служение» в том же разделе.
*   **Задача (6): Компактный список напоминаний.**
    *   Вместо технических «0 дн.» → текст: день недели, время, статус ✅/⏸, начало текста.
    *   Под списком — кнопки «1», «2», … для быстрого доступа к конкретному напоминанию.
*   **Задача (8): Быстрый выход из настроек.**
    *   «Закрыть настройку» → сразу на главный экран служения (без промежуточных экранов).

### Шаг 5д. Унификация экранов служения ⬜
*   **Задача (15): Хлебные крошки навигации.**
    *   Заголовок экрана — текстовый путь: «ЗВУК › 📅 График › Обзор».
    *   Последний пункт меняется динамически по нажатой кнопке.
*   **Задача (12, 13): Экран настроек служения.**
    *   Название подключённого чата и список админов кликабельными ссылками (tg://user?id или @username).
    *   «⛔ Отключить служение» на этом экране, только суперадмину.
*   **Задача (14): Переименование кнопки графика.**
    *   В «📅 График» кнопка «График» → «Обзор».
*   **Задача (11): Короткие имена для ответственных.**
    *   Поле в карточке человека: «Василий», «В. П.» (для графиков и напоминаний).
    *   Полное имя остаётся для сверки Excel. Пусто — используется как сейчас.

### Шаг 5е. Опрос по дням и режимы ✅ (PR #92, PR #93 deploy в test)
*   **Задача (17): Нагрузка в днях месяца.**
    *   ✅ Расчёт по фактическим дням служения; мягкий лимит (может быть превышен при нехватке).
*   **Задача (18): Свобода выбора в опросе.**
    *   ✅ Опрос по конкретным дням с задачами; можно отметить день одной задачи
        без других дней недели (связка работает по настройкам ответственного).
*   **Задача (21): Режим «Опрос наоборот».**
    *   ✅ Люди отмечают дни, когда НЕ МОГУТ служить; ответ переворачивается для алгоритма.
    *   Не ответившие остаются резервом (не считаются свободными везде).
